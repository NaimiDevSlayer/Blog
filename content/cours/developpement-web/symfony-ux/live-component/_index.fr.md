**Live Components en pratique** est un cours gratuit basé sur une série de vidéos YouTube ([NAIMI Dev Slayer](https://youtube.com/@NaimiDevSlayer)) pour construire des interfaces dynamiques avec **Symfony UX**, en PHP et en Twig, sans écrire de JavaScript :

- Créer des Live Components : propriétés, actions, rendu en temps réel
- Afficher des graphiques avec Chart.js
- Rendre un graphique interactif avec un filtre
- Intégrer DataTables dans un Live Component
- Initialiser un composant avec `mount()` et ajouter l'autocomplétion
- Découper un tableau de bord en composants qui communiquent entre eux

Suis les chapitres ci-dessous dans l'ordre, en même temps que les vidéos. Le code complet est sur GitHub : [saif1919/symfony_ux_tuto](https://github.com/saif1919/symfony_ux_tuto).

> **Versions utilisées :** Symfony **7.3**, Symfony UX **2.27**, AssetMapper (sans Webpack), Bootstrap 5.
