**Live Components in Practice** is a free course based on a YouTube video series ([NAIMI Dev Slayer](https://youtube.com/@NaimiDevSlayer)) to build dynamic interfaces with **Symfony UX**, in PHP and Twig, without writing JavaScript:

- Create Live Components: properties, actions, real-time rendering
- Display charts with Chart.js
- Make a chart interactive with a filter
- Integrate DataTables in a Live Component
- Initialize a component with `mount()` and add autocomplete
- Split a dashboard into components that talk to each other

Follow the chapters below in order, alongside the videos. The full code is on GitHub: [saif1919/symfony_ux_tuto](https://github.com/saif1919/symfony_ux_tuto).

> **Versions used:** Symfony **7.3**, Symfony UX **2.27**, AssetMapper (no Webpack), Bootstrap 5.

> The videos of this course are in French. Turn on YouTube's auto-translated subtitles if needed.
