**API Platform 4** est un cours gratuit basé sur une série de vidéos YouTube ([NAIMI Dev Slayer](https://youtube.com/@NaimiDevSlayer)). On y construit une API REST d'articles et d'auteurs, puis on la sécurise :

- Créer une ressource et choisir ses opérations HTTP
- Paginer, valider et contrôler les données renvoyées
- Filtrer et trier les collections
- Personnaliser la lecture et l'écriture avec les providers, les processors et les DTO
- Sécuriser l'API avec JWT et les refresh tokens

Suis les chapitres ci-dessous dans l'ordre, en même temps que les vidéos. Le code complet est sur GitHub : [saif1919/apiplatformv4tuto](https://github.com/saif1919/apiplatformv4tuto).

> **Versions utilisées :** API Platform **4.0**, Symfony **7.1**, PHP **8.2**, MySQL. API Platform a pas mal évolué depuis (la dernière version 4.x est la 4.4) : quand une partie a changé, un encadré te le signale dans le chapitre.
