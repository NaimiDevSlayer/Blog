**Mini Bibliothèque** est un cours gratuit basé sur une série de vidéos YouTube ([NAIMI Dev Slayer](https://youtube.com/@NaimiDevSlayer)) dans laquelle on construit, de A à Z, une application de bibliothèque numérique avec **Symfony 8** :

- Un catalogue public avec couvertures de livres
- Un lecteur PDF intégré, pour lire les livres directement en ligne
- Un back-office complet avec **EasyAdmin** (livres, auteurs, catégories, utilisateurs...)

Suis les chapitres ci-dessous dans l'ordre pour reproduire le projet en même temps que la vidéo.
