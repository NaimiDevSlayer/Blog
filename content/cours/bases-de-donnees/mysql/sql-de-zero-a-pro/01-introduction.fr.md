Bienvenue dans cette nouvelle série où on plonge dans le monde de **SQL**, le langage essentiel pour gérer et interroger des bases de données. Que tu débutes, que tu veuilles rafraîchir tes connaissances ou simplement comprendre pourquoi SQL est partout dans la tech, tu es au bon endroit.

## Le programme

Voici ce qu'on va voir, chapitre par chapitre :

1. **Qu'est-ce que SQL ?** Pourquoi ce langage est si important dans la gestion des bases de données modernes, puis l'**installation de MySQL**, l'un des systèmes de gestion de bases de données les plus populaires.
2. **Gérer les bases de données** : les créer, les supprimer, les renommer et naviguer entre elles.
3. **Gérer les tables** : les créer, les modifier, les relier entre elles, puis **insérer, modifier et supprimer** des données.
4. **Extraire les données** avec `SELECT` : filtrer, trier, regrouper et calculer.
5. **SQL avancé** : les **sous-requêtes**, pour des interrogations plus puissantes.
6. **SQL avancé** : les **jointures**, pour relier les données de plusieurs tables.
7. **Exercices pratiques**, en deux parties, pour mettre en application tout ce qu'on a appris.

L'objectif : qu'à la fin du cours, tu repartes avec une **vraie expérience pratique** de SQL.
