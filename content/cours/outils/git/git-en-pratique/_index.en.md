**Git in Practice** is a free course based on a YouTube video series ([NAIMI Dev Slayer](https://youtube.com/@NaimiDevSlayer)) to learn how to use **Git** every day:

- Install and configure Git
- Clone a project, create branches, commit and push
- Put a project on GitHub with `git init`
- Set work aside with `git stash`
- Write clean, readable commits
- Pick a branching strategy for your team
- Contribute with forks and pull requests
- Keep a repository tidy and review your changes

Follow the chapters below in order, alongside the videos.

> The videos of this course are in French. Turn on YouTube's auto-translated subtitles if needed.
