**Git en pratique** est un cours gratuit basé sur une série de vidéos YouTube ([NAIMI Dev Slayer](https://youtube.com/@NaimiDevSlayer)) pour apprendre à utiliser **Git** au quotidien :

- Installer et configurer Git
- Cloner un projet, créer des branches, committer et pousser
- Mettre un projet sur GitHub avec `git init`
- Mettre son travail de côté avec `git stash`
- Faire des commits propres et lisibles
- Choisir une stratégie de branches pour son équipe
- Contribuer avec les forks et les pull requests
- Garder un dépôt propre et vérifier ses modifications

Suis les chapitres ci-dessous dans l'ordre, en même temps que les vidéos.
